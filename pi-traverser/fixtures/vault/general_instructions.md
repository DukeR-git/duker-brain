# General Instructions

Fallback guide, used when routing is inconclusive.

- Match the surrounding code's style, naming, and comment density.
- Prefer the smallest change that solves the stated problem.
- When a library is involved, check its version in the lockfile before assuming an API.
- Do not add dependencies without saying so explicitly.
